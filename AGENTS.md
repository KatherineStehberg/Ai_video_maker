# Instrucciones para agentes

Leer las instrucciones vigentes del repositorio, incluido CLAUDE.md cuando exista, antes de modificar código o datos. Conservar cambios ajenos.

Para slides animadas, procesos, datos o transformaciones didácticas de Language Center Chile, usar `$lc-course-animations` en `.agents/skills/lc-course-animations/SKILL.md`. El paquete incluye generador HTML + GSAP, renderer MP4 y reglas de QA/WordPress. Usar la marca LC y contenido real de la lección.

Esta skill se invoca desde un agente o CLI: su instalación no activa un worker, un endpoint ni publicaciones automáticas. Registrar sólo etapas verificadas.
